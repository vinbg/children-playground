# Детска площадка зад бл. 602, ж.к. „Дружба“

Предложение на живущи в района за инициативата [„Идеи за града 2027“](https://reshava.sofia.bg/processes/idei-za-grada-2027) на Столична община (районен граждански бюджет, район „Искър“).

Идеята е неизползваемата кучешка площадка с чакъл в ПИ 68134.1500.2678 да стане детска площадка. В нея има гумена настилка, пясъчник, съоръжения за катерене и високи светлопропускливи сенници.

**Интерактивна схема:** https://vinbg.github.io/children-playground/
